# Quickstart: проверка «Моего списка»

## Подготовка

```bash
pytest tests/unit/test_watchlist.py tests/unit/test_imdb.py tests/unit/test_backend.py tests/unit/test_player_ipc.py
cd app && npm run check && npx vitest run && npm run tauri dev
```

Файл списка: `%APPDATA%\mpv-cinema-launcher\watchlist.json`. Перед проверкой сделайте копию, если он есть.

## Сценарии

1. **Статус (US1)**: открыть фильм → «Добавить в список» → «Запланировано». Кнопка синяя (`#23436f`). Перезапустить приложение и открыть фильм снова: статус «Запланировано».
2. **Один тайтл через два источника**: у того же фильма включить источник Lampac — статус тот же, в файле одна запись.
3. **id IMDb**: через несколько секунд после открытия известного фильма (например, «Матрица», 1999) ключ записи в файле стал `tt0133093`, статус сохранился.
4. **Удаление**: «Удалить из списка» → тайтл пропал из «Моего списка», в файле запись с `deleted_at`.
5. **«Мой список» (US2)**: три тайтла с разными статусами. Счётчики на вкладках верные, фильтры показывают только свои тайтлы, свежие сверху, клик открывает страницу.
6. **Серии (US3)**: у сериала в панели «Эпизоды» отметить кружками 3 серии сезона 1 → «3 / M» в заголовке панели и на полосе «Просмотрено», статус «Смотрю». Снять одну → «2 / M», статус прежний. Клик по строке серии загружает её, строка подсвечивается.
7. **Автоматика (US4)**: запустить фильм не из списка → «Смотрю». Перемотать на последние секунды и досмотреть → предложение «Отметить как просмотренное?», «Да» → «Просмотрено». То же для mpv в отдельном окне и во встроенном плеере.
8. **Прерванный просмотр**: закрыть mpv на середине → предложения нет, серия не отмечена.
9. **Повреждённый файл**: закрыть приложение, записать в `watchlist.json` мусор, запустить → предупреждение, пустой список, рядом `watchlist.broken-*.json`.
10. **Без сети**: отключить сеть, поставить статус → сохраняется (запасной ключ), ошибок нет.
11. **Объём**: подставить файл с 500 записями → «Мой список» открывается и фильтрует без заметной задержки.
