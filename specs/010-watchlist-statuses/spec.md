# Feature Specification: Мой список со статусами просмотра

**Feature Branch**: `010-watchlist-statuses`

**Created**: 2026-11-16

**Status**: Draft

**Input**: User description: "Локальный список фильмов и сериалов со статусами просмотра (issue #11, этап «Список и статусы просмотра»). Статусы — только три: Смотрю / Просмотрено / Запланировано. Ключ — IMDb id, при отсутствии — id КиноПоиска; одна запись для kinogo и Lampac. Отметки просмотренных серий, updated_at, tombstones. Локальный JSON. Автоматика: запуск → «Смотрю»; досмотрено → предложить «Просмотрено». Дропдаун статуса под постером; экран «Мой список» с фильтром. Google-вход, синхронизация и редизайн — вне рамок."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Поставить статус фильму или сериалу (Priority: P1)

На странице фильма или сериала пользователь открывает выпадающий список под постером и выбирает «Смотрю», «Запланировано» или «Просмотрено». Можно и убрать тайтл из списка. Выбор сохраняется сразу и остаётся после перезапуска приложения.

**Why this priority**: Без этого нет самого списка, остальное строится на нём.

**Independent Test**: Открыть любой фильм, выбрать «Запланировано», перезапустить приложение, открыть тот же фильм — статус «Запланировано».

**Acceptance Scenarios**:

1. **Given** тайтла нет в списке, **When** открыта его страница, **Then** под постером кнопка «Добавить в список» нейтрального цвета.
2. **Given** тайтла нет в списке, **When** пользователь выбирает «Запланировано», **Then** кнопка показывает «Запланировано» в цвете статуса, тайтл появляется в списке.
3. **Given** у тайтла статус «Смотрю», **When** пользователь выбирает «Просмотрено», **Then** статус меняется, запись остаётся одна.
4. **Given** тайтл в списке, **When** пользователь выбирает «Удалить из списка», **Then** тайтл исчезает из списка и кнопка снова «Добавить в список».
5. **Given** тайтл в списке, найденный через kinogo, **When** тот же тайтл открыт через Lampac, **Then** показывается тот же статус.

---

### User Story 2 - Экран «Мой список» (Priority: P1)

Пользователь открывает экран «Мой список» и видит постеры всех тайтлов из списка. Вкладки фильтра: «Все», «Смотрю», «Запланировано», «Просмотрено» — с количеством. По клику на тайтл открывается его страница.

**Why this priority**: Список нужен, чтобы им пользоваться: вернуться к начатому и выбрать из запланированного.

**Independent Test**: Добавить три тайтла с разными статусами, открыть «Мой список», переключать фильтры — видны только тайтлы выбранного статуса, счётчики совпадают.

**Acceptance Scenarios**:

1. **Given** в списке 2 «Смотрю» и 1 «Запланировано», **When** открыт «Мой список», **Then** вкладка «Все» показывает 3 тайтла, «Смотрю» — 2, «Запланировано» — 1, «Просмотрено» — 0.
2. **Given** открыт фильтр «Смотрю», **When** пользователь кликает по тайтлу, **Then** открывается его страница.
3. **Given** список пуст, **When** открыт «Мой список», **Then** показано пустое состояние с подсказкой, как добавить тайтл.
4. **Given** на экране есть тайтлы, **When** пользователь смотрит на порядок, **Then** сначала те, что менялись недавно.

---

### User Story 3 - Отметки просмотренных серий (Priority: P2)

На странице сериала у каждой серии есть отметка «просмотрено». Пользователь может отметить серию вручную или снять отметку. Рядом со статусом показано «N / M» серий выбранного сезона.

**Why this priority**: Для сериалов статус без прогресса малополезен, но список работает и без этого.

**Independent Test**: Отметить 3 серии первого сезона, перезапустить приложение — 3 серии отмечены, показано «3 / M».

**Acceptance Scenarios**:

1. **Given** сериал без отметок, **When** пользователь отмечает серию 1 сезона 1, **Then** серия помечена, а сериал получает статус «Смотрю», если статуса не было или был «Запланировано».
2. **Given** серия отмечена, **When** пользователь снимает отметку, **Then** отметка исчезает, статус не меняется.
3. **Given** у сериала два сезона, **When** пользователь переключает сезон, **Then** отметки и «N / M» показываются для выбранного сезона.

---

### User Story 4 - Автоматические статусы при просмотре (Priority: P2)

При запуске просмотра тайтл сам получает «Смотрю». Когда фильм или последняя серия досмотрены, приложение предлагает отметить «Просмотрено». Для сериала досмотренная серия отмечается автоматически.

**Why this priority**: Убирает ручную работу, но не обязательна для первого результата.

**Independent Test**: Запустить фильм не из списка — он появился в «Смотрю»; досмотреть до конца — появилось предложение «Отметить как просмотренное?».

**Acceptance Scenarios**:

1. **Given** тайтла нет в списке или у него «Запланировано», **When** пользователь запускает просмотр (встроенный плеер или mpv), **Then** статус становится «Смотрю».
2. **Given** у тайтла «Просмотрено», **When** пользователь запускает просмотр снова, **Then** статус не меняется.
3. **Given** идёт серия сериала, **When** просмотр доходит до конца, **Then** серия отмечается просмотренной.
4. **Given** идёт фильм или последняя серия последнего сезона, **When** просмотр доходит до конца, **Then** появляется ненавязчивое предложение «Отметить как просмотренное?»; согласие ставит «Просмотрено», отказ ничего не меняет.

---

### Edge Cases

- У тайтла нет ни IMDb id, ни id КиноПоиска: запись создаётся по запасному ключу (нормализованное оригинальное название + год + тип). Когда id становится известен, запись переводится на него без потери статуса и отметок.
- Один и тот же тайтл найден через разные источники с разными названиями: если совпадает IMDb id или id КиноПоиска, запись одна.
- Тайтл удалён из списка, затем добавлен снова: создаётся заново, отметки серий не возвращаются.
- Файл списка повреждён или нечитаем: приложение запускается с пустым списком, повреждённый файл сохраняется рядом как резервная копия, пользователь видит предупреждение.
- Приложение закрыто во время сохранения: при следующем запуске список в последнем полностью сохранённом состоянии.
- Постер больше не загружается: в «Мой список» показывается заглушка с названием.
- Просмотр прерван до конца: «Просмотрено» не предлагается, серия не отмечается.
- Число серий у источника изменилось (вышли новые): отметки старых серий сохраняются, «N / M» пересчитывается.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Система MUST поддерживать ровно три статуса: «Смотрю», «Запланировано», «Просмотрено», с цветами #3d3475, #23436f и #2c5e2c соответственно.
- **FR-002**: Пользователь MUST иметь возможность поставить, сменить и снять статус тайтла выпадающим списком под постером на странице тайтла.
- **FR-003**: Система MUST определять тайтл по IMDb id; если его нет — по id КиноПоиска; если нет обоих — по запасному ключу (оригинальное название + год + тип).
- **FR-004**: Система MUST показывать одну и ту же запись для одного тайтла независимо от источника (kinogo или Lampac).
- **FR-005**: Запись MUST хранить: ключ, название, оригинальное название, постер, год, тип (фильм/сериал), статус, отметки просмотренных серий по сезонам, время последнего изменения.
- **FR-006**: Удаление тайтла MUST оставлять пометку об удалении со временем удаления (для будущей синхронизации); удалённые тайтлы не показываются нигде в интерфейсе.
- **FR-007**: Список MUST храниться локально на устройстве и сохраняться между перезапусками без входа в какой-либо аккаунт.
- **FR-008**: Каждое изменение MUST сохраняться так, чтобы сбой во время записи не терял ранее сохранённые данные.
- **FR-009**: Система MUST предоставлять экран «Мой список», доступный из главной навигации, с фильтром «Все / Смотрю / Запланировано / Просмотрено» и количеством тайтлов в каждом.
- **FR-010**: Экран «Мой список» MUST сортировать тайтлы по времени последнего изменения, новые сверху, и открывать страницу тайтла по клику.
- **FR-011**: Для сериалов пользователь MUST иметь возможность отметить и снять отметку «просмотрено» у каждой серии в панели «Эпизоды» справа (номер, название, кружок-отметка, текущая серия подсвечена, счётчик «N / M» в заголовке, выбор сезона); под фактами о тайтле — полоса «Просмотрено N / M» для выбранного сезона (по референсу anime.mamoru.fun, решение владельца 2026-11-16).
- **FR-012**: Запуск просмотра MUST ставить статус «Смотрю», если тайтла нет в списке или у него «Запланировано»; статус «Просмотрено» не меняется.
- **FR-013**: Досмотренная до конца серия MUST автоматически отмечаться просмотренной.
- **FR-014**: После досмотра фильма или последней серии последнего сезона система MUST предлагать отметить «Просмотрено» и менять статус только с согласия пользователя.
- **FR-015**: При повреждённом файле списка система MUST запускаться, сохранять копию повреждённого файла и сообщать об этом пользователю.
- **FR-016**: Когда у записи с запасным ключом становится известен IMDb id или id КиноПоиска, система MUST перевести запись на этот ключ, сохранив статус и отметки.

### Key Entities

- **Запись списка**: один тайтл в личном списке. Ключ (IMDb / КиноПоиск / запасной), отображаемые данные (название, оригинальное название, постер, год, тип), статус, отметки серий, время последнего изменения, признак удаления.
- **Статус**: одно из трёх значений — Смотрю, Запланировано, Просмотрено; у каждого фиксированный цвет и подпись.
- **Отметки серий**: набор просмотренных серий по сезонам для сериала; принадлежит записи.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Поставить статус тайтлу со страницы можно в 2 клика.
- **SC-002**: 100% статусов и отметок сохраняются после перезапуска приложения.
- **SC-003**: Экран «Мой список» с 500 тайтлами открывается и переключает фильтры без заметной задержки (менее 1 секунды).
- **SC-004**: Один и тот же тайтл, открытый через kinogo и через Lampac, в 100% случаев с известным IMDb id или id КиноПоиска показывает один статус.
- **SC-005**: Принудительное закрытие приложения во время изменений не приводит к потере ранее сохранённого списка.

## Assumptions

- Источники (страница kinogo, ответы Lampac) позволяют получить IMDb id или id КиноПоиска хотя бы для большинства тайтлов; если нет, работает запасной ключ.
- «Досмотрен до конца» означает воспроизведение до последних ~5% длительности или до конца файла — одинаково для встроенного плеера и mpv.
- Статусы «Отложено», «Брошено», «Пересматриваю» не нужны.
- Список один, для одного пользователя устройства; без аккаунтов.
- Вход через Google, синхронизация через Google Drive и редизайн страницы тайтла — отдельные фичи; здесь только задел (время изменения, пометки удаления).
- Текущий дизайн приложения сохраняется; новые элементы оформляются в его стиле.
