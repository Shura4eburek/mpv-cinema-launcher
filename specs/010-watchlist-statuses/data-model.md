# Data Model: Мой список со статусами просмотра

## Файл `watchlist.json`

```json
{
  "version": 1,
  "items": {
    "tt0133093": { "...": "запись" },
    "t:film:2026:bitva motorov": { "...": "запись" }
  },
  "lookups": {
    "t:film:2026:bitva motorov": { "imdb": null, "checked_at": "2026-11-16T12:00:00Z" }
  }
}
```

## Запись (`items[key]`)

| Поле | Тип | Правила |
|------|-----|---------|
| `key` | str | `tt\d+` / `kp:\d+` / `t:<film\|series>:<год>:<название>`; совпадает с ключом в `items` |
| `fallback_key` | str | запасной ключ; по нему найдётся запись, если id ещё не известен на другом устройстве |
| `title` | str | русское название, непустое |
| `orig_title` | str \| null | |
| `poster_url` | str \| null | http(s) |
| `source` | `"kinogo"` \| `"hdrezka"` \| `"lampac"` \| null | источник страницы; нужен, чтобы открыть тайтл из списка (адрес KinoGo переводится на текущее зеркало) |
| `year` | str \| null | 4 цифры |
| `kind` | `"film"` \| `"series"` | |
| `url` | str | адрес страницы kinogo, http(s) |
| `status` | `"watching"` \| `"planned"` \| `"completed"` \| null | null только у удалённой записи |
| `episodes` | `{ "<сезон>": ["<серия>", …] }` | только у `series`; серии без повторов, в порядке возрастания |
| `updated_at` | str | ISO 8601 UTC; меняется при любом изменении |
| `deleted_at` | str \| null | пометка удаления; удалённая запись не показывается, `episodes` очищаются |

## Статусы

| Значение | Подпись | Цвет |
|----------|---------|------|
| `watching` | Смотрю | `#3d3475` |
| `planned` | Запланировано | `#23436f` |
| `completed` | Просмотрено | `#2c5e2c` |

## Переходы статуса

| Событие | Было | Стало |
|---------|------|-------|
| Выбор в списке | любой / нет | выбранный |
| «Удалить из списка» | любой | удалена (`deleted_at`) |
| Запуск просмотра | нет, удалена, `planned` | `watching` |
| Запуск просмотра | `watching`, `completed` | без изменений |
| Ручная отметка серии | нет, удалена, `planned` | `watching` |
| Досмотр серии | любой | серия отмечена, статус как при запуске |
| Согласие на «Просмотрено?» | любой | `completed` |

Повторное добавление удалённой записи снимает `deleted_at` и начинает с пустых `episodes`.

## Поиск записи по странице

1. Есть id (из `lookups` по запасному ключу) → `items[id]`.
2. Иначе `items[fallback_key]`.
3. Иначе запись с таким `fallback_key` под любым ключом.

## Перенос на id (FR-016)

Когда для запасного ключа найден id: запись `items[fallback_key]` переезжает в `items[id]`. Если под id уже есть запись, побеждает более свежий `updated_at`, а `episodes` объединяются. Старый ключ получает пометку удаления, чтобы будущая синхронизация не вернула его.

## `lookups[fallback_key]`

| Поле | Тип | Правила |
|------|-----|---------|
| `imdb` | str \| null | найденный id или null («не найдено») |
| `checked_at` | str | ISO 8601; «не найдено» повторяется не раньше чем через 7 дней |
