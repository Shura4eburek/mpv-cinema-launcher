# Contract — GUI-приложение и упаковка

## GUI-поведение (точка входа бандла)

Запуск без аргументов (двойной клик):

| Ситуация | Поведение | Код выхода |
|----------|-----------|------------|
| В буфере валидная `.m3u8` + mpv найден | запуск mpv (профиль `auto`, пресет `film`) | код mpv (0 при норме) |
| В буфере нет пригодной ссылки | нативный диалог «скопируйте ссылку и запустите снова» | 3 |
| mpv не найден нигде | нативный диалог с подсказкой по установке | 4 |

- GUI **не** пишет ошибки в stderr как основной канал — только нативный диалог
  (stderr — лишь фолбэк, если механизм диалога недоступен).
- Профиль/пресет в GUI фиксированы умолчаниями (`auto`/`film`); флагов нет.

## find_mpv()

- Возвращает абсолютный путь к mpv или `None`.
- Порядок: PATH → типичные места установки по ОС (см. data-model).
- Не бросает исключений.

## show_error(message)

- Показывает ровно одно модальное окно с `message` и кнопкой OK.
- Никогда не роняет приложение (все ошибки механизма — в тихий фолбэк).

## Упаковка (артефакты сборки)

| Платформа | Команда (build-скрипт) | Артефакт |
|-----------|------------------------|----------|
| macOS | `build/build_macos.sh` | `dist/mpvplay.app` + `dist/mpvplay.dmg` |
| Windows | `build/build_windows.ps1` | `dist/mpvplay/…/mpvplay.exe` (onedir) |

Контрактные ожидания к бандлу:
- запускается на машине **без установленного Python** (SC-004);
- внутри лежат `mpv-profiles/*.conf`, и приложение их находит во frozen-режиме (SC-005);
- окна консоли при запуске нет (`--windowed` / `console=False`);
- сам mpv в бандл не входит — берётся установленный в системе.
