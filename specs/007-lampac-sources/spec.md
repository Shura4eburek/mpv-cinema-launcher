# Feature Specification: Источники Lampac

**Feature Branch**: `007-lampac-sources`

**Created**: 2026-11-02

**Status**: Draft

**Input**: User description: "Подключить Lampac NextGen (lampac-nextgen/lampac, локальный сервер источников) как дополнительные источники фильмов и сериалов: на странице фильма показывать источники Lampac с озвучками и качеством и запускать их в нашем плеере mpv."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Другие источники фильма (Priority: P1)

Зритель открывает страницу фильма. Рядом с текущим источником появляется блок «Другие источники»: список сайтов, где фильм найден. Зритель выбирает источник, озвучку и качество и нажимает «Смотреть». Фильм открывается в привычном плеере с той же обработкой изображения.

**Why this priority**: Это главная ценность: больше озвучек и качества, и фильм можно посмотреть, даже если основной сайт недоступен.

**Independent Test**: Открыть «Довод» и «Интерстеллар», выбрать по одному источнику из блока, дойти до воспроизведения.

**Acceptance Scenarios**:

1. **Given** Lampac работает, **When** открыта страница фильма, **Then** блок показывает найденные источники по мере проверки, не мешая кнопке «Смотреть» основного источника.
2. **Given** выбран источник, **When** зритель выбирает озвучку и качество, **Then** эти варианты относятся к выбранному источнику.
3. **Given** выбран вариант, **When** зритель нажимает «Смотреть», **Then** фильм запускается в плеере, показывается экран «Открываем плеер», и его можно отменить.
4. **Given** выбранный вариант не запустился, **When** плеер сообщил о сбое, **Then** зритель видит понятное сообщение и может выбрать другой источник.
5. **Given** Lampac выключен или недоступен, **When** открыта страница фильма, **Then** блока нет, а основной источник работает как раньше.

---

### User Story 2 - Включение Lampac (Priority: P1)

Зритель включает Lampac в настройках и видит его состояние: выключен, запускается, работает, ошибка с причиной. Больше ничего настраивать не нужно.

**Why this priority**: Без этого зритель не сможет пользоваться источниками.

**Independent Test**: Установить приложение, включить Lampac, дождаться состояния «Работает», выключить.

**Acceptance Scenarios**:

1. **Given** Lampac выключен, **When** зритель его включает, **Then** видны запуск и итоговое состояние.
2. **Given** запуск не удался, **When** зритель открывает настройки, **Then** он видит причину.
3. **Given** Lampac работает, **When** зритель закрывает приложение, **Then** приложение не оставляет запущенных им процессов.
4. **Given** Lampac работает, **When** другой компьютер в сети обращается к нему, **Then** соединение не устанавливается.

---

### User Story 3 - Сериалы (Priority: P2)

Зритель открывает сериал, выбирает источник, сезон, серию и озвучку и смотрит выбранную серию.

**Why this priority**: Сериалы нужны, но сначала надо подтвердить работу подключения на фильмах. Сейчас приложение сериалы не поддерживает.

**Independent Test**: Открыть один сериал, запустить вторую серию второго сезона.

**Acceptance Scenarios**:

1. **Given** источник сообщает сезоны и серии, **When** зритель их выбирает, **Then** запускается именно выбранная серия.
2. **Given** у сериала нет сезонов в источнике, **When** он открыт, **Then** источник не предлагается.

### Edge Cases

- Фильм не найден ни в одном источнике: блок сообщает об этом одной строкой.
- Источник проверяется долго: остальные показываются сразу, зависший не мешает.
- Одноимённые фильмы разных лет: поиск идёт с учётом года; не тот фильм можно заметить по источнику и закрыть.
- Порт уже занят другой программой: состояние «Ошибка» с причиной.
- Ссылка варианта устарела: перед запуском она запрашивается заново.
- Источнику нужен платный аккаунт или браузер для обхода защиты: источник не используется.
- Новая версия Lampac изменила ответы: блок скрывается с записью в журнале, основной источник работает.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Настройки ДОЛЖНЫ позволять включить и выключить Lampac; по умолчанию он выключен.
- **FR-002**: Настройки ДОЛЖНЫ показывать состояние Lampac и причину сбоя.
- **FR-003**: Lampac и всё нужное для его работы ДОЛЖНЫ входить в установщик приложения: зрителю не нужно ничего скачивать и ставить отдельно.
- **FR-004**: Сервер Lampac ДОЛЖЕН быть доступен только с этого компьютера.
- **FR-005**: При закрытии приложения ДОЛЖНЫ завершаться все запущенные им процессы Lampac.
- **FR-006**: Страница фильма ДОЛЖНА показывать источники по мере проверки и не ждать их для показа основного источника.
- **FR-007**: Зритель ДОЛЖЕН иметь возможность выбрать источник, озвучку и качество из того, что сообщил источник.
- **FR-008**: Запуск ДОЛЖЕН идти через существующий плеер с пресетами, экраном «Открываем плеер» и отменой.
- **FR-009**: Сбой Lampac НЕ ДОЛЖЕН влиять на поиск и просмотр через KinoGo и HDRezka.
- **FR-010**: ДОЛЖНЫ использоваться только источники без платного аккаунта и без браузера для обхода защиты. Разделы для взрослых и лишние службы Lampac (торренты, DLNA, транскодирование, синхронизация) ДОЛЖНЫ быть выключены.
- **FR-011**: Для сериалов ДОЛЖЕН быть выбор сезона и серии (история 3).
- **FR-012**: Экран проверки зеркал ДОЛЖЕН показывать состояние Lampac.

### Key Entities

- **Источник Lampac**: название, найден ли фильм, ссылка на варианты.
- **Вариант просмотра**: озвучка, качество, сезон и серия при наличии, ссылка на поток и нужные для неё заголовки.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Из 10 проверочных фильмов разных лет у 9 или больше есть хотя бы один дополнительный источник, с которого фильм запускается.
- **SC-002**: Основной источник появляется не позже, чем сейчас, с точностью до 0,5 с, при любом состоянии Lampac.
- **SC-003**: Первые источники появляются в блоке не позже чем через 10 секунд после открытия страницы.
- **SC-004**: После закрытия приложения в 100% проверок не остаётся запущенных им процессов Lampac.
- **SC-005**: Lampac не отвечает на запросы с других компьютеров в 100% проверок.
- **SC-006**: С выключенным Lampac приложение не тратит на него ни сеть, ни запуск процессов.

## Assumptions

- Подтверждено пробой: Lampac NextGen 1.87.6 работает на этом компьютере с переносимым ASP.NET Core Runtime 10, слушает только `127.0.0.1` и отдаёт источники по HTTP. Запуск из установщика ещё не проверен.
- Lampac подключается как отдельная программа без изменений. Его код AGPL-3.0 не копируется в проект. Он входит в установщик, поэтому при передаче установщика другим людям нужно выполнять условия AGPL: приложить лицензию и дать исходный код Lampac. Установщик вырастет примерно до 130 МБ, на диске около 235 МБ.
- Модуль Kinogo в Lampac требует браузер, поэтому не используется; KinoGo остаётся нашим источником.
- Модуль Rezka в Lampac относится к платным и не используется; HDRezka остаётся нашей.
- Каталог поиска не меняется: поиск идёт как сейчас, источники Lampac появляются на странице найденного фильма.
- Lampac обновляется вместе с приложением, новым установщиком; автообновление не входит в работу.
