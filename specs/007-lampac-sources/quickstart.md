# Quickstart: проверка

Автотесты: `pytest tests -q`; в `app/`: `npm test`, `npm run check`.

В песочнице, из собранного установщика без установки в систему:

1. Выключено: нет процессов Lampac и запросов к нему, страница фильма как раньше.
2. Включение: «Запускается», затем «Работает»; порт слушает только `127.0.0.1`.
3. Журнал: загружены только разрешённые модули, 18+ нет.
4. «Довод»: источники появляются до 10 с; LordFilm запускается в плеере с выбранной озвучкой, отмена работает.
5. 10 фильмов разных лет: у 9 или больше есть источник, с которого фильм запускается.
6. Закрытие приложения и аварийное завершение backend: процессов Lampac не остаётся.
7. Занятый порт: сервер берёт другой или показывает причину.
8. KinoGo работает при упавшем Lampac.
