# Research: Источники Lampac

Проба 2026-11-02: Lampac NextGen 1.87.6 из архива релиза, переносимый ASP.NET Core Runtime 10.0.14, без установки, `listen.ip = 127.0.0.1`, браузеры отключены.

## 1. Запуск на Windows

**Проверено**: сервер отвечает через 12 с, слушает только `127.0.0.1:19118`, с адреса локальной сети соединение не устанавливается. Память: 369 МБ после запуска, 494 МБ после запросов.

**Решение**: запускать `dotnet.exe Core.dll` из своего рантайма, с `DOTNET_MULTILEVEL_LOOKUP=0`, без окна. Порт выбирается свободный при запуске.

## 2. Размер

| Часть | МБ на диске |
|-------|-------------|
| `.playwright` (браузерный движок) | 578 |
| `runtimes` (в основном для других систем) | 236 |
| `module` | 203 |
| `data`, `wwwroot` и прочее | около 80 |
| ASP.NET Core Runtime | 105 |
| Всего | около 1200 |

**Проверено (T001)**: из архива оставлены только модули `Online`, `OnlineRUS`, `OnlineUKR`, `Proxy`; из `runtimes` только `win`, `win-x64` и `references` (без `references` сервер не запускается: там `Serilog.dll`); `.playwright` убран. Настройка `SkipModules` не нужна: лишних модулей просто нет.

| Показатель | Значение |
|------------|----------|
| На диске с рантаймом | 235 МБ |
| В архиве с рантаймом | 106 МБ, значит установщик около 130 МБ |
| Запуск | 18 с |
| Память после запроса источников | 367 МБ |
| Загруженные модули | только онлайн-источники RUS и UKR и прокси, 18+ и служб нет |

Сервер слушает только `127.0.0.1:19118`, источники для «Довод» пришли за 8 с: VeoVeo, Kinoteatr.kg, LordFilm, Eneyida с `type: movie` проверены не все, Aladin и HDVB также отмечены рабочими. Ошибок компиляции и браузера в журнале нет. Запуск из установщика ещё не проверялся.

## 3. Где он работает

Lampac пишет `cache`, `database`, `logs` рядом с `Core.dll`. **Решение**: установщик кладёт его в ресурсы, при первом включении файлы копируются в каталог данных приложения, запуск оттуда.

## 4. Какие источники

Без платных аккаунтов и браузера на «Довод» и «Интерстеллар»:

| Источник | Что отдал | Запуск в mpv |
|----------|-----------|--------------|
| LordFilm | 6–7 озвучек, 720p, субтитры | работает, 7 с |
| Eneyida | одна дорожка, субтитры, 1080p по имени файла | работает, 4 с (Интерстеллар) |
| Kinoteatr.kg | одна дорожка | работает, 4 с (Довод); на Интерстелларе ответ не JSON |
| VeoVeo | «Оригинал», одна дорожка | работает, но 19–29 с |
| Filmix | только 480p без аккаунта; «Довод» заглушка `abuse` | работает, 5 с |
| Aladin, HDVB | тип `similar`: нет прямого совпадения | не проверялось |

Пробы mpv подтверждают только успешное декодирование 40 кадров без окна. Настоящее разрешение, звук и озвучка в обычном плеере не проверялись.

**Вывод**: Lampac даёт резервные источники и больше озвучек, но бесплатные варианты в основном не лучше 720p и не заменяют настоящий 1080p KinoGo.

**Решение**: в установщик входят только группы `OnlineRUS` и `OnlineUKR`, модули `Online` и `Proxy`. `OnlinePaid` (в том числе Filmix), `OnlineGEO`, `OnlineENG`, `OnlineAnime`, 18+ и прочие службы не поставляются. Браузерные модули загружаются, но при выключенном браузере не предлагаются; это проверяется по списку источников.

## 5. Как спрашивать

**Проверено**: `GET /lite/events?id=…&serial=0&title=…&original_title=…&year=…` отдаёт список за 8 с, `GET {url}&rjson=true` отдаёт JSON: `type` (`movie`, `similar`), `data[]` с `url`, `quality`, `translate`, `subtitles`, `voice[]` с собственными ссылками.

**Ловушка**: с `id=0` все пять фильмов получили один и тот же список за 0,0 с: кеш Lampac ключуется по `id`. **Решение**: передавать устойчивое число из хеша «название + год».

**Ловушка**: флаг `show: true` не значит, что фильм найден: Aladin и HDVB дают `similar`, а часть ответов не JSON. **Решение**: источник показывается только после разбора ответа с `type: movie`. `similar` используется, только если год и название совпали точно. Заглушка с `abuse` в адресе отбрасывается.

**Постепенный показ**: проверено: `/lite/events?life=true` и опрос `/lifeevents`; первые источники за 0,5–1 с, все за 8 с.

**Сериалы**: проверено на «Во все тяжкие» и «Мир Дикого запада». С `serial=1` источник отдаёт `type: season` со ссылками на сезоны, ссылка ведёт на `type: episode` с `s`, `e`, `name`, `quality` и `voice[]`. Серии VeoVeo и LordFilm декодировались в mpv. VeoVeo на «Мир Дикого запада» отдал `type: movie`, такой ответ отбрасывается.

**SC-001**: 10 из 10 фильмов: у каждого хотя бы один источник декодируется в mpv. LordFilm и Kinoteatr.kg обычно за 4–13 с, VeoVeo 5–36 с и один тайм-аут, Eneyida один сбой. VeoVeo часто отдаёт только оригинал, поэтому по умолчанию открывается источник с большим числом озвучек.

**Ограничение**: потоки LordFilm и Kinoteatr.kg идут через локальный прокси Lampac. Если закрыть приложение во время просмотра, такой фильм остановится, а прямые потоки продолжат играть.

## 6. Завершение

Сервер работает с дочерним `conhost.exe`. **Решение**: Windows Job Object с `KILL_ON_JOB_CLOSE`, чтобы процессы завершались и при аварийном закрытии приложения.

## 7. Лицензия

Lampac (AGPL-3.0) остаётся отдельной неизменённой программой. Установщик содержит текст лицензии и ссылку на исходный код версии 1.87.6. Настройка `init.conf` код не меняет.

## 8. Защита сайтов

Браузерные модули выключены. `Kinogo` в Lampac не используется. Это сохраняет обещание спецификации 004 не применять маскировку браузера.
