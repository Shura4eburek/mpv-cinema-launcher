# CLI Contract — mpv HLS Launcher

Внешний интерфейс лаунчера — командная строка. Это контракт, который проверяется
юнит-тестами (сборка команды) и quickstart-сценариями.

## Вызов

```text
mpvplay [URL] [options]
python -m mpv_launcher [URL] [options]
```

- `URL` — необязательный позиционный аргумент: ссылка на HLS-поток.
  Если не передан — берётся из буфера обмена.

## Опции

| Флаг | Значение | По умолчанию | Назначение |
|------|----------|--------------|------------|
| `--profile` | `auto\|desktop-4070ti\|air-m1\|generic` | `auto` | класс машины / профиль апскейла |
| `--film` | — | (вкл.) | пресет контента: кино/сериалы |
| `--anime` | — | — | пресет контента: аниме (взаимоисключим с `--film`) |
| `--referer` | `URL` | — | заголовок Referer |
| `--user-agent` | `STR` | — | заголовок User-Agent |
| `--header` | `"Name: Value"` | — | произвольный заголовок; можно повторять |
| `--dry-run` | — | — | напечатать собранную команду mpv и выйти (не запускать) |
| `-h`, `--help` | — | — | справка |

## Коды выхода

| Код | Условие |
|-----|---------|
| `0` | mpv запущен успешно (или `--dry-run` отработал); далее код проксирует mpv |
| `2` | ошибка разбора аргументов (например, `--film` и `--anime` вместе) |
| `3` | ссылка не найдена/непригодна (пустой аргумент и буфер, или не-URL) |
| `4` | mpv не установлен (нет в PATH) |
| `>0` | иное — проксируется код возврата mpv |

## Поведение (контрактные ожидания)

1. **URL из аргумента** имеет приоритет над буфером обмена.
2. **URL из буфера**: если аргумент пуст — читается буфер; берётся первая непустая
   строка; если пусто/не-URL → код `3` и сообщение на stderr.
3. **Сборка команды** (проверяется в `--dry-run`): argv mpv заканчивается на `URL`;
   `--http-header-fields=` присутствует только если задан хотя бы один заголовок;
   порядок заголовков — `referer`, `user-agent`, затем `--header` в порядке передачи.
4. **Профиль `auto`** разрешается в конкретный по эвристике детекции; при неуверенности
   → `generic` (щадящий).
5. **Отсутствие `.conf`-профиля** → предупреждение на stderr + базовый встроенный
   апскейл; код выхода не меняется из-за этого.
6. **mpv не в PATH** → код `4` и подсказка по установке; mpv не вызывается.
7. Все сообщения об ошибках идут в **stderr**, полезный вывод (`--dry-run`) — в **stdout**.

## Примеры

```bash
# Ссылка аргументом, автопрофиль, кино по умолчанию
mpvplay "https://cdn.example/.../hls-v1-a4.m3u8"

# Из буфера обмена, аниме-пресет
mpvplay --anime

# Форсировать тяжёлый профиль и задать Referer
mpvplay "https://..." --profile desktop-4070ti --referer "https://site.example/"

# Посмотреть, что соберётся, без запуска
mpvplay "https://..." --anime --dry-run
```
