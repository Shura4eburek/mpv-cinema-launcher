# Data Model: Поддержка сериалов

## Новые сущности (`scraper.py`)

### Episode

| Поле | Тип | Заметки |
|------|-----|---------|
| `id` | str | HDRezka: `data-episode_id`; KinoGo: номер из текста кнопки |
| `name` | str | «Серия 3» |

### Season

| Поле | Тип | Заметки |
|------|-----|---------|
| `id` | str | HDRezka: `data-tab_id`; KinoGo: номер из текста кнопки |
| `name` | str | «Сезон 2» |
| `episodes` | list[Episode] | KinoGo: заполнены только у текущего сезона, см. ниже |

### SeriesInfo

| Поле | Тип | Заметки |
|------|-----|---------|
| `seasons` | list[Season] | непустой |
| `season` | str | id текущего сезона |
| `episode` | str | id текущей серии |
| `moved` | bool | запрошенной серии нет, выбрана ближайшая |

**KinoGo**: плеер показывает серии только текущего сезона. Остальные сезоны приходят с пустым `episodes`, список появляется после выбора сезона. Интерфейс должен это учитывать.

## Изменения

### MovieDetails

| Поле | Тип | Заметки |
|------|-----|---------|
| `series` | SeriesInfo \| None | `None` у фильма |
| `switched_from` | str \| None | `"kinogo"`, если страница автоматически открыта с HDRezka |

## Правила

- **Сериал**: `series` не `None` только при наличии серий (группа серий у KinoGo, `.b-simple_episode__item` у HDRezka).
- **Ближайшая серия** (`nearest_episode`): та же; иначе в том же сезоне серия с ближайшим номером; иначе ближайший по номеру сезон и его первая серия. Если выбрана не запрошенная, `moved = true`. Смена сезона в интерфейсе передаёт `episode: null`: это первая серия и `moved = false`.
- **Нечисловые id**: сравниваются по первому числу в строке; если числа нет, выбирается первая серия.
- **Ключ потоков**: `(адрес, озвучка, сезон, серия, источник)`.
- **Ключ обновлённых ссылок**: `(адрес, озвучка, сезон, серия)`.

## Состояния выбора в интерфейсе

```text
готово -- выбор сезона/серии/озвучки --> загрузка -- успех --> готово (новый выбор)
                                         загрузка -- ошибка --> ошибка потока (выбор остаётся, можно выбрать другое; если серии нового сезона неизвестны, возвращается прежний выбор с его потоками)
                                         загрузка -- отмена --> готово (прежний выбор и потоки)
```
