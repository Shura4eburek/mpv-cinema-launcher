# Contract: изменения протокола для сериалов

Дополняет [протокол 003](../../003-app-player-ui/contracts/backend-protocol.md). Существующие методы для фильмов не меняются.

## `movie`: новые поля результата

```json
{
  "series": {
    "seasons": [{"id": "1", "name": "Сезон 1", "episodes": [{"id": "1", "name": "Серия 1"}]}],
    "season": "1",
    "episode": "1",
    "moved": false
  },
  "switched_from": null
}
```

У фильма `series` равно `null`. `switched_from` равно `"kinogo"`, когда `url` в ответе ведёт на HDRezka вместо запрошенной страницы.

## Новый метод `episode`

Выполняется в очереди Selenium. Шаги загрузки идут событием `load_progress`, отмена через `cancel`.

| Параметр | Тип | Обязателен | Заметки |
|----------|-----|-----------|---------|
| `url` | str | да | `http` или `https` |
| `source` | str | да | `kinogo` или `hdrezka` |
| `translator_id` | str | нет | пусто: текущая озвучка |
| `season` | str | да | |
| `episode` | str \| null | нет | `null`: первая серия сезона |
| `voice_optional` | bool | нет | `true` при смене сезона или серии: если озвучки нет в новом сезоне, остаётся озвучка плеера, и это не ошибка. Выбранная зрителем озвучка передаётся без этого признака |
| `progress_id` | str | нет | |

Результат:

```json
{
  "streams": {"1080p": ["https://..."]},
  "translators": [{"id": "12", "name": "Амедиа", "active": true}],
  "active_translator_id": "12",
  "series": {"seasons": [], "season": "2", "episode": "3", "moved": false}
}
```

Ошибки: `no_streams` (видео серии нет), `network` (страница не загрузилась), `cancelled`, `invalid_params`.

Новый запрос к сайту не выполняется, если такой ответ младше 5 минут.

## `play`: новые необязательные параметры

`season` и `episode`: нужны при обновлении устаревшей ссылки KinoGo, чтобы вернулась та же серия. Для фильма не передаются. `title` собирает интерфейс: «Во все тяжкие — Сезон 2, Серия 3».

## Проверка входных данных

`season` и `episode` — непустые строки, HDRezka передаёт их запросом в контексте страницы только как значения параметров.
