# Quickstart: проверка сериалов

## Подготовка

```powershell
$env:PYTHONPATH="src"; python -m pytest
cd app; npm test; npm run check; npx tauri dev
```

Сайты живые: результат зависит от их доступности. Проверки ниже подтверждают требования спецификации.
