# Data Model: Новый интерфейс приложения и плеера

## UserSettings (файл настроек)

| Поле | Тип | По умолчанию | Правило |
|------|-----|--------------|---------|
| `version` | int | `1` | версия формата |
| `upscale_quality` | `max` \| `basic` | `max` | неизвестное значение (в т.ч. `balanced`) → значение по умолчанию |
| `content` | `film` \| `anime` | `film` | то же |
| `interpolation` | bool | `true` | не bool → значение по умолчанию |
| `profile` | `auto` \| `desktop-4070ti` \| `air-m1` \| `generic` | `auto` | то же |
| `last_translator` | string \| null | `null` | применяется, только если есть у фильма |
| `last_quality` | string \| null | `null` | применяется, только если есть у фильма |

Каждое поле проверяется отдельно. Повреждённый файл целиком заменяется значениями по умолчанию
в памяти, а исходный файл перезаписывается только при следующем сохранении.

## ViewState (состояние окна, в памяти Svelte)

| Поле | Назначение |
|------|------------|
| `screen` | `home` \| `results` \| `movie` |
| `query`, `results`, `scroll_position` | восстановление выдачи при возврате (FR-013) |
| `movie` | загруженная страница фильма |
| `request_id` | номер последнего запроса; ответы с другим номером отбрасываются |
| `status` | `idle` \| `loading` \| `empty` \| `error` с текстом и действием |

Переходы: `home → results → movie → results`. В `movie` запуск плеера экран не меняет.

## PlaybackRequest (расширение `Options` в cli.py)

| Поле | Назначение |
|------|------------|
| `title` | название в окне плеера; пусто → «Видео по ссылке» |

## UpscaleState (в `cinema.lua`, только во время просмотра)

- `disabled` — «Выключен»: список шейдеров пуст.
- `active` — «Работает»: шейдеры заданы, в рендере есть их проходы.
- `not_needed` — «Не требуется»: шейдеры заданы, проходов нет (например, масштаб 1:1).
- `unavailable` — «Недоступен»: шейдер задан, но не загрузился.

Переключение: `active`/`not_needed`/`unavailable` ↔ `disabled`.
