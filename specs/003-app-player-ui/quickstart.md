# Quickstart: проверка нового интерфейса

## Подготовка

```powershell
python -m pip install -e ".[dev]"
python -m pytest
cd app
npm install
npm test
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri dev
```

## Сквозной срез

1. Окно открывается раньше, чем готов backend, и при этом реагирует на действия.
2. Поиск возвращает результаты. В stderr-журнале нет ошибок протокола.
3. Завершить процесс backend в диспетчере задач: сообщение в окне, следующий поиск работает.
4. Закрыть окно: не остаётся процессов backend, `chromedriver` и headless Chrome.

## Плеер (US1)

1. Найти фильм и нажать «Смотреть»: в заголовке и на панели название, а не ссылка.
2. Подвигать мышь: панель появляется. Подождать 3 секунды: панель и курсор скрываются.
3. Нажать на шкалу: перемотка работает, во время загрузки виден индикатор.
4. Сменить дорожку и субтитры мышью на видео, где они есть: фильм не перезапускается.
5. Проверить `Space`, `f`, стрелки, `Shift+I`: горячие клавиши работают.
6. Запустить ссылку из буфера: подпись «Видео по ссылке».

## Приложение (US2)

1. Выполнить поиск: сетка постеров, при изменении ширины меняется число колонок.
2. Открыть фильм и вернуться: запрос и прокрутка на месте.
3. Быстро запустить поиск и сразу новый: на экране результат последнего запроса.
4. Отключить сеть и выполнить поиск: сообщение и кнопка «Повторить» внутри окна.
5. Уменьшить окно до минимума: все элементы управления доступны.

## Настройки и апскейл (US3)

1. Изменить настройки и перезапустить приложение: значения сохранены.
2. Испортить файл настроек и запустить приложение: запуск со значениями по умолчанию.
3. В плеере открыть «Качество картинки»: разрешение совпадает с `ffprobe` и `Shift+I`.
4. На весь экран — «Работает». В окне 1:1 (`f`, затем размер окна как у видео) — «Не требуется».
5. Выключить апскейл: состояние «Выключен», фильм не перезапускается. Включить обратно.

## Регрессия

- `mpvplay --search "Тенет" --dry-run`: команда содержит название и аргументы скина, URL последний.
- Первая ссылка мертва: приложение переключается на зеркало (проверка из исправления mirror-failover).
- Каталог `mpv-profiles/player` временно переименован: фильм запускается со стандартным OSC.
- Название фильма с HTML-разметкой показывается как обычный текст.

## Установщик

1. Собрать `build\build_windows.ps1` и установить приложение.
2. Без Python в `PATH` проверить поиск, постеры и запуск фильма: всё работает, окна консоли нет.
