# Research: загрузка и пресеты

## R1. Шаги загрузки

- **Decision**: объект `Progress` с контекстом `step(name)`: начало, завершение и ошибка шага отправляются автоматически. Шаги KinoGo: `page`, `player`, `stream`, `voice`, `quality`, `fallback`. HDRezka: `page`, `voice`.
- **Rationale**: шаги отражают реальный код, поэтому их нельзя показать «вперёд» работы (FR-007).
- **Alternatives**: процент по времени — выдуманный прогресс, запрещён FR-007.

## R2. Отмена

- **Decision**: метод `cancel` выполняется сразу, вне очереди Selenium. Циклы ожидания проверяют флаг. Если задача не завершилась за 3 секунды, закрывается Chrome: `driver.get` нельзя прервать иначе. Следующая загрузка запускает новый Chrome.
- **Статус**: укладывается ли это в 5 секунд, проверяется в установленном приложении.

## R3. Определение видеокарты

- **Decision**: Windows — SetupAPI через `ctypes`, без PowerShell (`EnumDisplayDevices` в сессии удалённого рабочего стола видит только виртуальный адаптер); macOS — `sysctl machdep.cpu.brand_string`; Linux — `lspci` с таймаутом. Виртуальные адаптеры отбрасываются, из настоящих берётся лучший класс.
- **Rationale**: запуск PowerShell занимает заметное время и открывает лишний процесс.

## R5. Профили

- **Decision**: High — текущий `desktop-4070ti.conf`. Новые профили без привязки к платформе: `mid.conf` (FSRCNNX x8, KrigBilateral, Anime4K M) и `low.conf` (простое масштабирование без шейдеров). `air-m1.conf` остаётся для CLI.
- **Rationale**: в `air-m1.conf` есть параметры только для macOS.
