# Quickstart: проверка встроенного плеера

## Подготовка

```powershell
$env:PYTHONPATH="src"; python -m pytest
cd app; npm test; npm run check; cargo test --manifest-path src-tauri/Cargo.toml
npx tauri dev
```

## Проба наложения (тестовое видео, без сети)

Для способов А, Б и В: показать панель с полупрозрачным фоном и кнопкой, снять снимок экрана и заполнить таблицу в research.md.

| # | Действие | Записать |
|---|----------|----------|
| 1 | Панель над движущимся видео | Видна ли, видно ли видео сквозь полупрозрачную часть |
| 2 | Нажать кнопку панели | Сработала ли |
| 3 | Нажать и навести курсор на uosc вне панели | Реагирует ли плеер |
| 4 | Двигать окно и менять размер | Отставание, мерцание |
| 5 | Полный экран и обратно | Панель на месте, окно вернулось |

Способ А собирается отдельно с прозрачным окном. После него проверить обычный режим: снимок не должен отличаться.
