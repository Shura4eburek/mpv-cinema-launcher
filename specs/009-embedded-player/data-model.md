# Data Model: Плеер внутри окна приложения

## Настройка

| Поле | Тип | По умолчанию | Правила |
|------|-----|--------------|---------|
| `embedded_player` | bool | `false` | На macOS игнорируется и не показывается. Читается при каждом запуске плеера |

## Область видео

Дочернее окно в окне приложения; существует только в процессе Rust.

| Поле | Тип | Заметки |
|------|-----|---------|
| `wid` | целое | Идентификатор окна для `--wid`. Передаётся backend только как целое положительное число |
| видимость | bool | Показывается после сигнала первого кадра, скрывается по завершении плеера |

## Состояния просмотра

```text
страница фильма -- «Смотреть» --> запуск (ход загрузки на месте постера, область скрыта)
запуск -- первый кадр --> просмотр (область на месте постера)
запуск -- отмена или ошибка --> страница фильма (прежнее сообщение)
просмотр -- конец фильма --> просмотр (последний кадр, плеер остаётся)
просмотр -- закрытие плеера --> страница фильма с постером
просмотр -- сбой плеера --> страница фильма с постером и сообщением
просмотр -- другая серия или озвучка --> прежний процесс завершается --> запуск на том же месте
просмотр -- уход со страницы или настройки --> просмотр останавливается
любое -- закрытие приложения --> плеер завершается, приложение закрывается
```
