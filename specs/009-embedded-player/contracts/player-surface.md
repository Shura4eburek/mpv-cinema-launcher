# Contract: область видео

Дополняет [протокол 003](../../003-app-player-ui/contracts/backend-protocol.md). Режим отдельного окна не меняется.

## Команды Tauri (интерфейс → Rust)

Только Windows. На другой системе возвращают ошибку `unsupported`.

| Команда | Параметры | Результат | Смысл |
|---------|-----------|-----------|-------|
| `player_surface_create` | — | `{wid: number}` | Создать скрытую область, повторный вызов возвращает ту же |
| `player_surface_show` | `x, y, width, height, clip_top` | — | Показать в этом прямоугольнике клиентской части окна, в точках CSS с учётом масштаба; выше `clip_top` видео обрезается по шапке |
| `player_surface_move` | `x, y, width, height, clip_top` | — | Переместить без смены фокуса; вызывается при прокрутке и изменении размера |
| `player_surface_hide` | — | — | Скрыть и вернуть фокус веб-виду |
| `player_surface_fullscreen` | `on: bool` | — | Развернуть окно и область на весь экран или вернуть прежнее место |

Положение области задаёт интерфейс: он наблюдает за элементом страницы и вызывает `player_surface_move`.

## Протокол backend

### `play`: новый необязательный параметр

`wid`: целое положительное число. Есть только при включённом режиме. Иное значение даёт `invalid_params`. На системе не Windows игнорируется.

`resume`: `true` при смене качества или озвучки той же серии. Новый плеер продолжает с места, где остановился прежний.

### Новый метод

`player_stop`, без параметров, результат `{ok: true}`: завершить встроенный плеер. Выполняется сразу. Если ссылка ещё обновляется, интерфейс дополнительно вызывает `cancel` с `progress_id` запуска.

### Новое событие

| Событие | Данные | Смысл |
|---------|--------|-------|
| `player_fullscreen` | `on: bool`, `id` | Плеер сменил свойство `fullscreen`; интерфейс вызывает `player_surface_fullscreen` |

События `playback_started`, `playback_finished`, `playback_failed`, `playback_fallback` прежние. Интерфейс показывает область по `playback_started` и скрывает по двум завершающим событиям; `playback_finished` приходит только после закрытия плеера зрителем.

## Настройки

`set_settings` принимает `embedded_player: bool`.

## Запуск mpv

При наличии `wid` план запуска дополняется аргументами `--wid=<wid>`, `--input-ipc-server=\\.\pipe\mpv-cinema-<случайное>` настройкой uosc без кнопок окна и `--keep-open=yes`, чтобы плеер оставался после конца фильма. Без `wid` аргументы прежние, это проверяется тестом.
