# Quickstart: проверка редизайна

## Подготовка

```bash
cd app && npx vitest run && npm run check && npm run tauri dev
```

Для проверки без backend: `npx vite`, в браузере заглушка `__TAURI_INTERNALS__` (как в 010).

## Сценарии

1. **Сериал (US1)**: три колонки при 1400 px; слева постер, статус, белая «Смотреть» и «Трейлер»; над названием бейджи (рейтинг, «Сериал», год, «N эп.»); чипы страны и режиссёра; жанры пилюлями; описание в карточке; справа «Эпизоды». Сравнить со скриншотами референса из ишью #11.
2. **Фильм (US1)**: правой колонки нет, центр шире; выбор озвучки и качества в центре.
3. **HDRezka**: открыть тайтл с HDRezka — есть бейджи длительности и возраста.
4. **Нет фактов**: тайтл без режиссёра и рейтинга — нет пустых бейджей и чипов.
5. **Ширина**: 1100 px — «Эпизоды» под информацией; 800 px — всё в одну колонку; горизонтальной прокрутки нет.
6. **Встроенный плеер (US2)**: включить в настройках, «Смотреть» у сериала → видео в центре, шапка «‹ Серия 1 ›», информация под колонками; «›» → серия 2; ✕ → информация вернулась. У фильма в шапке название без стрелок.
7. **Палитра (US3)**: главная, результаты, «Мой список», настройки, страница тайтла — фон чёрный, поверхности серые без синевы, акцент прежний.
8. **Состояния**: загрузка, ошибка загрузки, страница без видео с вариантами HDRezka, сообщение о смене источника — в центральной колонке.
