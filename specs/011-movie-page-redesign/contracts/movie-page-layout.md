# Contract: раскладка страницы тайтла

Протокол backend не меняется. Контракт описывает, что где находится на странице.

| Ширина окна | Фильм | Сериал |
|-------------|-------|--------|
| ≥ 1180 px | `[постер+действия] [информация]` | `[постер+действия] [информация] [Эпизоды]` |
| 860–1179 px | `[постер+действия] [информация]` | `[постер+действия] [информация]`, ниже `[Эпизоды]` на всю ширину |
| < 860 px | колонки друг под другом | колонки друг под другом |

## Левая колонка (сверху вниз)

1. Постер (ширина колонки).
2. `StatusPicker` (после загрузки страницы).
3. Ряд: «▶ Смотреть» (белая) | «Трейлер». Пока идёт загрузка — «Трейлер» один.

## Центральная колонка

Без плеера: бейджи → название → оригинальное название → чипы → полоса «Просмотрено» (сериал) → жанры → озвучка (фильм) и качество → сообщения (смена источника, перенесённая серия, ошибка потока) → карточка описания → актёры → копирование ссылки → Lampac.

С встроенным плеером: `PlayerBar` (‹ Серия N › или название, ✕) → видео 16:9 → ход загрузки и ошибки серии. Тот же блок сведений (не пересоздаётся) переносится сеткой строкой ниже, на всю ширину.
