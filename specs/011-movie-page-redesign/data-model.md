# Data Model: Редизайн страницы фильма

Новых сохраняемых данных нет. Вводится только вычисляемая структура для отображения.

## `TitleFacts` (результат `titleFacts(info_table, kind, episodeCount, seasonCount)`)

| Поле | Тип | Откуда |
|------|-----|--------|
| `year` | `string \| null` | «Год» или «Дата выхода»; единственный разбор года на странице |
| `badges` | `{ label: string; tone: "rating" \| "plain" \| "outline" }[]` | по порядку: рейтинг (`tone: "rating"`), тип, год, «N сез.» (сериал, `seasonCount > 1`) или «N эп.» (сериал из одного сезона, `episodeCount > 0`), «Время», «Возраст» (`tone: "outline"`) |
| `chips` | `{ label: string; value: string }[]` | «Страна», «Режиссер» (подпись «Режиссёр»), «Дата выхода» |
| `genres` | `string[]` | «Жанр», разбит по запятой, без пустых и повторов |
| `siteQuality` | `string \| null` | «В качестве» |

Правила:
- Рейтинг: из «Рейтинги» вида «КиноПоиск: 7.1, IMDb: 6.8» берётся первая пара; подпись «КП 7.1» или «IMDb 6.8». Без числа — бейджа нет.
- Год: «Год», иначе «Дата выхода» (прежний `movieFacts` убран, разбор один).
- Пустые значения не дают ни бейджа, ни чипа.

## `neighbourEpisodes(episodes, current)`

`{ previous: string | null; next: string | null }` — id соседних серий в списке сезона; `null` у краёв и если текущей серии нет в списке.
