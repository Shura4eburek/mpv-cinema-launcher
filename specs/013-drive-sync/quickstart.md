# Quickstart: проверка синхронизации

## Подготовка

- Настроенный Google-клиент (см. [012 quickstart](../012-google-auth/quickstart.md)), Drive API включён.
- Два устройства (или две копии приложения с разными каталогами данных) с одним аккаунтом.

## Автотесты

```bash
PYTHONPATH=src python -m pytest -o addopts="" -q -W ignore::DeprecationWarning
cd app && npx vitest run && npm run check
```

## Сценарии

1. **US1**: на A добавить фильм «Запланировано» → через ≤ 10 с индикатор «Синхронизировано»; перезапустить B → фильм в списке с тем же статусом.
2. **Конфликт**: на A и B изменить статус одной записи без сети, включить сеть сначала на A, потом на B → на обоих статус с B (более позднее изменение).
3. **Удаление**: удалить на A, синхронизировать B → записи нет; три перезапуска A и B — запись не вернулась.
4. **US2**: отключить сеть, изменить список → «Нет связи — изменения отправятся позже»; включить → в течение минуты «Синхронизировано».
5. **Отзыв доступа**: удалить доступ в myaccount.google.com → изменить список → «Нужно войти заново»; войти → изменения в облаке.
6. **US3 первый вход**: на чистом устройстве с непустым локальным списком войти → объединённый список на обоих устройствах.
7. **Выход**: «Выйти» → список на месте, индикатор «Только на этом устройстве», в облаке без изменений.
8. **Без входа**: в сетевых запросах backend нет обращений к `googleapis.com/drive`.
