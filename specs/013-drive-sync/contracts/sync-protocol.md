# Contract: методы и события синхронизации

JSON Lines, как остальные методы backend. `SyncState` — из [data-model.md](../data-model.md).

| Метод | Где | Параметры | Результат |
|-------|-----|-----------|-----------|
| `sync_get` | сразу | — | `SyncState` |
| `sync_now` | сразу (ставит запрос в поток `Syncer`) | — | `SyncState`; без входа — ошибка `signed_out` |

## События

| Событие | `data` | Когда |
|---------|--------|-------|
| `sync_changed` | `SyncState` | каждый переход состояния и изменение `pending` |
| `watchlist_reloaded` | `{}` | слияние изменило локальный список |

## Сообщения

| Случай | `state` | `message` |
|--------|---------|-----------|
| нет сети, 429, 5xx | `offline` | «Нет связи с Google Drive — изменения отправятся позже» |
| доступ отозван / истёк | `auth_required` | «Нужно войти заново, чтобы синхронизировать список» |
| битый облачный файл, `version` > 1 | `error` | «Список в облаке не читается — синхронизация остановлена» |
| 403 лимит запросов (`rateLimitExceeded`) | `offline` | как «нет сети» |
| 403, квота | `error` | «Google Drive отклонил запись: <причина>» |
| 401 после обновления токена | `error` | «Google Drive не принял доступ — попробуйте синхронизировать позже» |

## Текст индикатора (frontend, `describeSync`)

| `state` | Текст |
|---------|-------|
| `disabled` | «Только на этом устройстве» |
| `idle` | «Синхронизировано · <время>»; при `pending` — «Изменения ждут отправки» |
| `syncing` | «Синхронизация…» |
| `offline` | «Нет связи — изменения отправятся позже» (если `pending`), иначе «Нет связи» |
| `auth_required` | «Нужно войти заново» + переход в Настройки |
| `error` | `message` |

Кнопка «Синхронизировать» доступна в `idle`, `offline`, `error`.
