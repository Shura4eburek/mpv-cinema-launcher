# Data Model: KinoGo как основной источник

## MovieSearchResult (расширение)

| Поле | Значения | Назначение |
|------|----------|------------|
| `source` | `kinogo` \| `hdrezka` | откуда получена карточка; по умолчанию `hdrezka` |

## MovieDetails (расширение)

| Поле | Значения | Назначение |
|------|----------|------------|
| `source` | `kinogo` \| `hdrezka` | показывается на странице фильма |
| `referer` | строка | заголовок для запуска потока |
| `alternatives` | список карточек | фильмы HDRezka, если на KinoGo нет видео |

## Streams (потоки)

`{подпись: [адреса по порядку]}`. Подпись определяется по ширине: 1920 → `1080p`, 1280 → `720p`, 854 → `480p`, 640 → `360p`, 426 → `240p`. Если реальное качество проверить нельзя — `Качество не подтверждено`.

Порядок адресов варианта: проверенный узел → `atlas` → `cfnd`.

## UserSettings (расширение)

| Поле | По умолчанию | Правило |
|------|--------------|---------|
| `kinogo_url` | `https://uakinogo.io` | только `http` и `https` с непустым хостом; неверное значение заменяется значением по умолчанию |

## Обновление ссылки

Backend хранит время получения потоков по адресу фильма. Ссылка получается заново, если она старше 30 минут, времени нет или прошлый запуск не удался.
