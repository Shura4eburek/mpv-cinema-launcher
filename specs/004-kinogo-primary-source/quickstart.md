# Quickstart: проверка источника KinoGo

## Подготовка

```powershell
python -m pytest
cd app; npm test; npm run check; npx tauri dev
```

## Настоящий Full HD (US1)

1. Найти «Довод» и нажать «Смотреть» с качеством по умолчанию.
2. В плеере открыть «Качество картинки»: `1920×1080`.
3. Повторить на контрольном наборе из research.md: минимум 9 из 10 подтверждённых фильмов.
4. Во время запуска реклама не видна и не слышна.

## Запасные варианты (US2)

1. Задать в настройках неработающий адрес KinoGo и выполнить поиск: результаты HDRezka и сообщение о запасном источнике.
2. Открыть «Дюна: Часть вторая»: приложение предлагает варианты HDRezka и не запускает трейлер.
3. Отключить сеть: понятное сообщение и «Повторить».

## Озвучка (US3)

1. Открыть «Довод»: в списке озвучек есть «Гаврилов Андрей» и «English (Original)».
2. Выбрать другую озвучку: подписи качества обновляются, а «Смотреть» запускает выбранную озвучку.
3. Убедиться на слух, что звук соответствует выбору.

## Регрессия

- `python -m mpv_launcher.cli --search "Довод" --dry-run`: адрес `atlas` или узла, URL последний.
- Запуск по ссылке из буфера и фильм HDRezka работают.
- После закрытия окна нет `chromedriver` и headless Chrome.
