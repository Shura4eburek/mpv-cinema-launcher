# Contract: изменения протокола backend

Дополняет `specs/003-app-player-ui/contracts/backend-protocol.md`.

| Метод | Изменение |
|-------|-----------|
| `search` | сначала KinoGo, затем HDRezka; у каждой карточки есть `source` |
| `movie` | источник определяется по адресу; у результата есть `source`, `referer`, `alternatives` |
| `play` | новые необязательные поля `movie_url`, `quality`, `referer`; при устаревшей ссылке потоки получаются заново |
| `get_settings`, `set_settings` | новое поле `kinogo_url` |

`movie` для KinoGo без видео возвращает пустые `streams` и заполненные `alternatives`; если HDRezka ничего не нашла, `alternatives` пуст. Ошибка `network` означает, что страницу не удалось загрузить.

## Журнал

В stderr пишется источник, адрес хоста и причина перехода. Подписи и токены в журнал не пишутся.

## Аргументы mpv

Для всех запусков добавляется `--network-timeout=10`, чтобы недоступный узел не задерживал переход на запасной адрес.
